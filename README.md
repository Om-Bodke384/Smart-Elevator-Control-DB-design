# LiftGrid Systems — Elevator Control System

## What I Made
ER Diagram for a smart elevator control platform
for large commercial buildings across India

## Tool Used
Eraser.io — Entity Relationship Diagram

## Tables (9 Total)
- Building_details
- Floors
- Elevator
- Elevator_status
- Elevator_floor
- floor_request
- ride_assignment
- ride_logs
- maintenance

## What This Covers
- multiple buildings with floors and elevators
- elevator serving multiple floors
- floor requests and ride assignments
- ride history and logs
- elevator status tracking
- maintenance records
